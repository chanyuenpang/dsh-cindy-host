# dsh-cindy-host 0.1.29

## 本次发布

- 将已验收的 Host 源码同步到主仓库，发布 Git 标签和 npm 包。
- 运行逻辑与已在手机、桌面实测通过的 0.1.28 相同；保留繁忙时 pendingQueue、插话、ACK、推送与轮询的一致性修复。

- 同步依赖锁及版本化隔离 smoke 检查。

## 验证与边界

- 干净工作树安装依赖后运行全量测试及通道分类审计。
- 0.1.28 通过真实 DSH 繁忙 Agent 下第二条消息的 ACK/推送/轮询验证；用户已确认手机和桌面均正常。

## 运行要求与审计说明

要求已验证的 DSH 0.2.1-rc.3 与 Node >=22.16。安装：`dsh plugin add dsh-cindy-host@0.1.29`；Desktop 保留 profile 使用应用自带插件管理器。

`npm audit` 报告宿主 SDK 的 Zod 上游内存耗尽告警（GHSA-mrhx-c7xc-m3w5，经三个 DSH peer 链共报告 4 项 high）。未执行会引入不匹配 SDK 的强制升级；宿主依赖修复不属于本次 Host-only 发布。
